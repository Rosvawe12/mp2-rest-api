This is a FastAPI web app where you upload your CSV file and it saves it in memory with an ID. You check the API is running with GET /health, upload the CSV with POST /upload, and get rows  out with GET /datasets/{id}. The main part is POST /datasets/{id}/process, which runs the data through the MP1 pipeline from before to validate it and clean it, which entails: removing duplicates, missing values, and outliers if you turn that on. After, it sends back a report of how many rows got removed. Every request gets logged with its own request ID, status code, and how long it took. 
Run command : `python -m pytest tests -v`
